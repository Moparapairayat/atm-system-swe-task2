# SE ATM UML Diagrams (Native Draw.io Studio) 🏧

This repository contains the native **Draw.io (`.drawio`) UML Diagram Suite** for an **Automated Teller Machine (ATM) System**.

---

## 📌 Native Draw.io Pages Included in `SE-ATM.drawio`

1. **1. Class Diagram**: Object-Oriented structure (Classes, Attributes, Methods, Composition, Inheritance, Associations).
2. **2. Use Case Diagram**: Actors (*Customer*, *Bank System*, *ATM Technician*), Use Cases (Ellipses), System Boundary, `«include»` relationships.
3. **3. Cash Withdrawal Sequence**: Actor lifelines, CardReader, ATM UI, ATM Controller, Core Bank Server, Cash Dispenser activation arrows.
4. **4. State Machine Diagram**: ATM state transitions (*Off*, *SelfTest*, *Idle*, *PIN Verification*, *Processing*, *Dispensing*, *Maintenance*).
5. **5. Activity Flowchart**: Decision diamonds (PIN validation, cash checks, bank authorization) and workflow arrows.
6. **6. Component Diagram**: Software modules, Hardware device drivers, HSM crypto engine, and Bank gateway components.
7. **7. Deployment Architecture**: 3D Nodes for ATM Terminal, Encrypted VPN Router, and Central Bank Data Center DB.

---

## 🚀 How to Open in Draw.io

1. **In VS Code**: Install the **Draw.io Integration** extension, then click on [SE-ATM.drawio](file:///d:/SE_ATM_UML_Diagram/SE-ATM.drawio).
2. **Online in Web Browser**: Go to **[app.diagrams.net](https://app.diagrams.net/)**, click *Open Existing Diagram*, and select `SE-ATM.drawio`.
